Exponent Laws

18 marks in test
⚡
Why this matters: 37% of your test marks come from simplifying expressions with exponents. Get these 8 rules into your bones and Q2 + Q4 become free marks.

The 8 Rules

Rule 1 — Multiply
am × an = am+n
Same base? Add the exponents.
e.g. x3 × x5 = x8
Rule 2 — Divide
am ÷ an = am−n
Same base? Subtract exponents.
e.g. x7 ÷ x2 = x5
Rule 3 — Power of a Power
(am)n = am×n
Power outside bracket? Multiply.
e.g. (x3)4 = x12
Rule 4 — Power of a Product
(ab)n = an × bn
Power goes to each factor.
e.g. (2x)3 = 8x3
Rule 5 — Power of a Fraction
(a/b)n = an / bn
Power goes to top and bottom.
e.g. (x/3)2 = x2/9
Rule 6 — Zero Exponent
a0 = 1
Anything to the power 0 is 1.
e.g. 50 = 1, (3x)0 = 1
Rule 7 — Negative Exponent
a−n = 1 / an
Flip it! Negative means "one over".
e.g. x−3 = 1/x3
Rule 8 — Negative on a Fraction
(a/b)−n = (b/a)n
Flip the fraction, lose the minus.
e.g. (2/3)−2 = (3/2)2 = 9/4
⚠
Common trap: Rules 1 & 2 only work with the same base. You can't add exponents of x3 × y2 — they have different bases!
Worked Example 1
Simplify: 32012 ÷ 32010
Step 1
Same base (3), so use Rule 2: subtract exponents
= 32012 − 2010
Step 2
Simplify the exponent
= 32 = 9
Worked Example 2
Simplify: (−2c2d3)4
Step 1
Use Rule 4: the power goes to EVERY factor inside the bracket
= (−2)4 × (c2)4 × (d3)4
Step 2
(−2)4 = 16 (even power kills the negative). Use Rule 3 for the rest.
= 16c8d12
Worked Example 3
Simplify with positive exponents: (2a)−2 · b3
Step 1
Deal with the negative exponent first. Rule 7: flip it.
= 1/(2a)2 × b3
Step 2
Expand (2a)2 using Rule 4
= 1/(4a2) × b3
Step 3
Combine
= b3 / (4a2)
Worked Example 4
Simplify (positive exponents): j−2k3 ÷ j−4k−5
Step 1
Same bases — use Rule 2 for each base separately
= j(−2)−(−4) × k3−(−5)
Step 2
Careful with the double negatives: −(−4) = +4 and −(−5) = +5
= j2 × k8
Step 3
Both exponents are already positive. Done!
= j2k8

Scientific Notation

4 marks in test
🔎
The idea: Scientific notation writes any number as a × 10n where 1 ≤ a < 10 (one non-zero digit before the decimal point).
Big numbers
Move decimal LEFT
82 100 000 → 8.21 × 107
Count: decimal moved 7 places left
Small numbers
Move decimal RIGHT
0.00053 → 5.3 × 10−4
Count: decimal moved 4 places right
Already has ×10n?
Fix "a" first, adjust n
0.0077 × 105
= 7.7 × 10−3 × 105
= 7.7 × 102
To ordinary number
Move decimal by n places
5 501 × 10−6
= 0.005501
(move 6 places left)
Worked Example
Write 0,0077 × 105 in standard scientific notation
Step 1
First, write 0.0077 in scientific notation on its own
0.0077 = 7.7 × 10−3 (moved decimal 3 places right)
Step 2
Now substitute back and combine the powers of 10 (Rule 1!)
= 7.7 × 10−3 × 105 = 7.7 × 10−3+5
Step 3
Simplify
= 7.7 × 102

Exponential Equations

13 marks in test
🎯
The golden rule: If the bases are the same, the exponents must be equal.
am = an ⇒ m = n

Your job: Rewrite both sides with the SAME base, then set exponents equal and solve.
Key Powers to Know
21=2   22=4   23=8   24=16   25=32   26=64   27=128
Know these by heart. They appear constantly.
More Key Powers
31=3   32=9   33=27   34=81
43=64   82=64
Notice: 64 = 26 = 43 = 82
Fractions = Negative Exponents
1/an = a−n
1/64 = 1/26 = 2−6
5/128 = 5/27 = 5 × 2−7
Strategy
1. Rewrite → 2. Match → 3. Solve
1. Make both sides same base
2. Set exponents equal
3. Solve the simple equation
Worked Example 1
Solve for x: 81 = 3x−2
Step 1
Rewrite 81 as a power of 3
81 = 34, so: 34 = 3x−2
Step 2
Same base ⇒ exponents are equal
4 = x − 2
Step 3
Solve
x = 6
Worked Example 2
Solve for x: 64x = 8
Step 1
Find a common base. 64 = 26 and 8 = 23
(26)x = 23
Step 2
Use Rule 3: (26)x = 26x
26x = 23
Step 3
Same base ⇒ 6x = 3
x = 1/2
Worked Example 3
Solve for x: 21−3x = 1/64
Step 1
Rewrite the right side: 1/64 = 1/26 = 2−6
21−3x = 2−6
Step 2
Same base ⇒ set exponents equal
1 − 3x = −6
Step 3
−3x = −7, so x = 7/3
x = 7/3
Worked Example 4 (the tricky one)
Solve for x: 5 · 2x = 5/128
Step 1
Divide both sides by 5 to isolate the exponential
2x = 1/128
Step 2
Rewrite: 128 = 27, so 1/128 = 2−7
2x = 2−7
Step 3
Same base ⇒ exponents equal
x = −7

Number Patterns

10 marks in test
💡
Pattern questions always follow the same steps:
1. Count the values for each figure
2. Find the common difference (how much it grows each time)
3. Write the rule: y = (common difference) × x + (adjustment)
4. Use the rule to find any figure number
Linear Pattern
y = mx + c
m = common difference
c = y-intercept (value when x=0)
or: c = first term − m
Finding the Rule
Step by step
1. Make a table of x and y
2. Find difference between y-values
3. That difference = m
4. Use any point to find c
Worked Example — Cross Pattern (like Q1)
Figures made of squares in a cross shape. Figure 1 has 5, Figure 2 has 9, Figure 3 has 13...
Step 1
Build the table and find the common difference
x: 1, 2, 3, 4    y: 5, 9, 13, 17    difference = 4
Step 2
Rule format: y = 4x + c. Use x=1, y=5 to find c.
5 = 4(1) + c  ⇒  c = 1
Step 3
Write the equation and verify
y = 4x + 1    Check: x=2 → y=9 ✓   x=3 → y=13 ✓
Worked Example — Finding a Figure Number (like Q6a)
A stick pattern grows by 8 sticks per figure. Figure 1 has 13 sticks. Which figure has 705 sticks?
Step 1
Write the rule: y = 8x + c. Use x=1, y=13.
13 = 8(1) + c  ⇒  c = 5  ⇒  y = 8x + 5
Step 2
Set y = 705 and solve for x
705 = 8x + 5  ⇒  700 = 8x
Step 3
Solve
x = 700 ÷ 8 = 87.5 ... hmm, check your count!
⚠
Counting tip for stick patterns: Count the sticks carefully in Figure 1 and Figure 2. Draw Figure 3 yourself to confirm the difference. One wrong count = wrong equation = lost marks.

Question 4
A right-angled triangle has A(−6, 4) and B(−6, −6). AB = BC and the right angle is at B. If C is to the right of B, what are the coordinates of C?
AB is vertical (same x-value). Length of AB = |4 − (−6)| = 10. BC must be horizontal and length 10. B is at (−6, −6).
